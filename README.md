# socialmedia AI

适合初学者维护的原生 HTML、CSS、JavaScript 应用。无框架、无第三方运行依赖，Node.js 22 或更高版本即可。

## 本地使用

在本文件所在文件夹打开终端，依次运行：

```
npm install
npm test
npm run build
npm run dev
```

浏览器打开 http://localhost:5173 。关闭预览：终端按 Ctrl+C。也可以把 dist 文件夹交给静态托管服务。

## 维护指南

- index.html：界面文字和结构。
- style.css：颜色、布局和手机适配。
- generator.js：各平台演示文案模板。
- app.js：表单、预览编辑、复制交互。
- generator.test.js：模板功能测试。
- build.js：把网页文件复制到 dist，属于静态构建。
- server.js：仅供本机预览的服务器。

## 功能与限制

支持填写产品信息、三个平台、三种风格、生成、编辑、字符统计和复制。输出和复制内容均有演示标记。信息只在当前页面内存中使用，刷新后清空。模板不会理解或翻译输入，建议用英文填写。X 正文模板限制为 240 个 Unicode 字符；演示标记会额外占用字符，正式发布前需要重新审核。长输入可能被截断。

没有真实 AI、账号、云端保存、发布、排程或平台接口。下一步先验证模板流程，再增加安全的后端 AI 接口，密钥只能保存在服务器；随后考虑历史记录和用户登录。
